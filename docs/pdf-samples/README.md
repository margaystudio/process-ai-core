# Muestras del formato PDF objetivo

Mockups generados con WeasyPrint (el mismo motor que corre en producción) durante el
diseño del formato del documento aprobado, julio 2026.

- `muestra_pdf_v2_APROBADO.pdf` — portada con acta de aprobación, header corrido, pie
  de tres campos, tablas de actores / riesgos / indicadores, chips "A VALIDAR".
- `muestra_pdf_v2_BORRADOR.pdf` — el mismo documento sin aprobar: bloque de
  invalidación y marca de agua.

Son **referencia de proporciones, jerarquía y tratamiento**, no código a copiar: están
hechos con HTML de ejemplo, no con el pipeline real.

Spec completa: Notion → Process AI → "📄 Formato del documento aprobado".
